# HFPC Backstage

Build a premium, modern, responsive corporate website for HFPC — Hospitality Facilities Planning Consultancy, using the attached HFPC Company Profile PDF as the primary and authoritative source for all company-specific information.

IMPORTANT SOURCE RULE:

Read and use the attached HFPC Company Profile PDF carefully.

Extract the company's actual services, sectors, capabilities, positioning, terminology, project information, contact information, and other factual details from the PDF.

Do NOT invent clients, certifications, statistics, years of experience, projects, awards, locations, testimonials, or business claims that are not supported by the PDF.

If the PDF does not contain a specific fact, leave a clear placeholder rather than making one up.

Preserve HFPC's actual terminology and positioning.

Do not make HFPC look like a generic web-development company or a generic hotel company.

HFPC is a specialist hospitality/facilities planning consultancy.

REFERENCE WEBSITE:
Use https://thsconsulting.in/ as a UX / information-architecture reference only.
Study the reference conceptually:

navigation structure

service organization

industry organization

project/gallery presentation

service detail pages

process/methodology sections

knowledge hub

enquiry/contact flow

multi-step project inquiry

responsive behavior

CTA placement

credibility sections

Do NOT copy THS's branding, text, layouts pixel-for-pixel, imagery, logo, or visual identity.
HFPC should have its own stronger and more premium identity.
